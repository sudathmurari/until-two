How do I share the log with my partner?

Settings → Care file → Send a care file. On the other iPhone, open the file with Until Two, or use Settings → Care file → Import a care file. Each import merges the new entries, so you can send it after every shift.

Each care file asks for a password when you send it. Tell it to the other person yourself, not in the same chat as the file. Nothing opens the file without it.

How do I move to a new phone?

Send a care file to yourself, by AirDrop or to Files, before you set up the new phone. On the new phone, choose Open a care file on the welcome screen.

Is there a backup?

The log is on this phone only. Save a care file to Files now and then. If Files is set to iCloud Drive, that copy is kept by iCloud under Apple's terms.

How do I start a timer without opening the app?

Add an Until Two widget to the Home Screen or the Lock Screen, or add its control to Control Center. A running timer shows on the Lock Screen and in the Dynamic Island, where you can pause or stop it. You can also say "Log a wet diaper in Until Two" or "Start nursing in Until Two" to Siri.

How do I ask a question about the log?

On an iPhone with Apple Intelligence and iOS 26.4 or later, open Insights and type or speak into Ask, or say "Ask Until Two" to Siri. The answer lists the entries it used, so you can check it. Settings → Intelligence shows whether this iPhone can answer. Answers can be wrong, and Ask does not give medical advice.

Accessibility

Until Two follows the system's dark appearance and has a night theme for a dark room. Text keeps at least WCAG AA contrast in every theme. Animation stops when Reduce Motion is on. Every activity is named in words, not only by its colour. If something is hard to use with VoiceOver, larger text, or anything else, please write to the address above.

Is it really free?

Yes. A dad built Until Two after his little one was born. It is free, and it will stay free: no subscription, no ads, and no in-app purchases.

How do I delete everything?

Settings → Delete the log, then type DELETE. Removing the app also erases the log.

Does Until Two give medical advice?

No. It records what you log. Growth charts name their source. For a concern about your baby, call your pediatrician.
