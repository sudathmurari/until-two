How do I share the log with my partner?

Settings → Care file → Send a care file. On the other iPhone, open the file with Until Two, or use Settings → Care file → Import a care file. Each import merges the new entries, so you can send it after every shift.

How do I move to a new phone?

Send a care file to yourself, by AirDrop or to Files, before you set up the new phone. On the new phone, choose Open a care file on the welcome screen.

Is there a backup?

The log is on this phone only. Save a care file to Files now and then. If Files is set to iCloud Drive, that copy is kept by iCloud under Apple's terms.

How do I start a timer without opening the app?

Add an Until Two widget to the Home Screen or the Lock Screen, or add its control to Control Center. A running timer shows on the Lock Screen and in the Dynamic Island, where you can pause or stop it.

How do I delete everything?

Settings → Delete the log, then type DELETE. Removing the app also erases the log.

Does Until Two give medical advice?

No. It records what you log. Growth charts name their source. For a concern about your baby, call your pediatrician.
